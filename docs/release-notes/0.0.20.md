**Updates that do not get stuck on the Mac, and a map that shows what is really there.**

> The application's interface is in Italian.

> **On the Mac, install this version by hand once** if 0.0.19 did not install itself: from here on an update that cannot replace the app opens its disk image instead of stopping.

### Fixed

- **A field emptied in the card disappears from the map too**: speed, VLAN and ports of a cable, network and VLAN of a zone, address and ports of a device.
- **The Mac could not install an update by itself.** Every step now has a second way, and the message says which step failed and what macOS answered (details in `DuckNote-update/aggiornamento.log` in the temporary folder).

### Changed

- **If the update cannot install itself, it opens**: on the Mac the verified disk image (**Apri l'aggiornamento**: drag DuckNote to Applications), on Windows the installer or the new `DuckNote.exe` in Explorer. A copy downloaded by DuckNote opens without the **Privacy e sicurezza** detour.
- **Updates are checked every six hours**, not only at startup.
- **Nothing stays highlighted in the sidebar** while **Rete**, **Mappa** or **Impostazioni** is open.
- **On Windows the map stays open** while you visit the other pages: coming back is instant.
- **Ready for Apple notarization**: with a Developer ID certificate in the repository secrets, the Mac app is signed, notarized and opens at the first double click.
