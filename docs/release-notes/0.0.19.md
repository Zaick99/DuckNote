**The network map.** Next to **Rete** there is now **Mappa**: draw the network as it is cabled — devices, cables with ports, speed and VLANs, zones for the subnets — and every device shows its state, on Windows and on the Mac.

> The application's interface is in Italian.

### Added

- **Mappa, a canvas for the network.** Devices of 14 kinds, cables and zones. Drag them from the library, or from **Dalla rete**: the hosts DuckNote already knows arrive with name, address, MAC, vendor and the kind of device the scan recognised. **Aggiungi tutti** brings in all those missing, each into the zone of its subnet. A note can hold several maps.
- **Live state.** Devices with an address are checked like the addresses of the sheets: green up, red down, grey never checked; a cable to a device that is down turns red and dashed.
- **Cables that document the network.** Copper, fibre, Wi-Fi, VPN, WAN; speed from 10M to 100G; the port at each end and the VLANs. Labels never cover each other: each finds a free place along its cable, or beside it with a dotted thread.
- **Switches show their front panel**: the ports in use, from the names of the cables, one click to the cable.
- **Zones** with network, VLAN and colour; a **VLAN** filter, search, **Disponi** (automatic layout), align and distribute, snapping, copy and paste, undo and redo.
- **Export** to PNG, SVG and CSV (device inventory, cable list).
- The map is saved inside the note: with encryption on, it is in the vault with everything else.

### Changed

- The note file keeps entries written by newer versions instead of dropping them.
- On Windows the map uses Microsoft Edge WebView2 (part of Windows 10 and 11), in private mode; without it, the map page says what to install.
- A new README, with screenshots of the real application.

From 0.0.18 on, DuckNote updates itself: this version arrives on its own and installs when DuckNote closes.

Not signed with a certificate: SmartScreen warns on the first run on Windows; on the Mac the app is ad-hoc signed, so the first time it is opened from **System Settings › Privacy & Security › Open Anyway**. `SHA256SUMS.txt` lists the hashes of every file — the same list the updater checks.
