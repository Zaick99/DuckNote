**DuckNote on the Mac.** The same note, vault and scanner now run on macOS, Apple Silicon and Intel, with the interface rebuilt on Avalonia and the sheet written in a native web view. On Windows, addresses written one after another are all checked again.

> The application's interface is in Italian.

### Added

- **A macOS application.** Notes, pages, the address colouring, **Rete** (Network) with the host card, **Impostazioni** (Settings) and the **Cassaforte** (vault) wizard work as on Windows, with the same files: a note or a `store.bin` written by one opens on the other. Drawings are the exception: ink drawn on Windows shows as a placeholder on the Mac and a Mac drawing shows empty on Windows, and both stay as they are until drawn again. The menu bar has **Nota**, **Modifica** and **Vista**; shortcuts use `⌘`.
- **The sheet is a native web view** (WKWebView on the Mac) running a rich-text editor built for DuckNote: titles, lists, checkboxes, quotes, code with colouring, tables, links, drawings, images and charts beside the text.
- **The local network permission.** From macOS 15 the system asks once whether DuckNote may reach the local network; without it pings, ports and names of LAN hosts fail.

### Fixed

- **Addresses written one after another are all checked.** A host that appeared while another analysis was running (typically the one written just before) waited for the next monitoring round, or forever with monitoring off, and the last one written stayed out of monitoring while the cursor was still next to it. Three names typed in a row (`PC0001.example.local PC0002.example.local PC0003.example.local`) are now all pinged as soon as you stop.
- **The scan summary counts the right hosts**: "3 host attivi su 3", not the whole table over the hosts of the last round.
