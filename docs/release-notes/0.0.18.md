**DuckNote updates itself.** From this version, on Windows and on the Mac, a newer release is downloaded, verified and installed when DuckNote closes — or at once with **Riavvia e aggiorna**.

> The application's interface is in Italian.

> **Install this version by hand once**: copies older than 0.0.18 do not check for updates. From here on, new versions arrive on their own.

### Added

- **Updates from GitHub, by themselves.** A few seconds after startup DuckNote asks GitHub, anonymously, for the latest release. If it is newer, it downloads the file for this installation (portable exe, installer, or the disk image for this Mac), keeps it only if its SHA-256 matches `SHA256SUMS.txt` of the same release, and installs it when DuckNote closes, with the note already saved. **Riavvia e aggiorna** in the notification does it at once and reopens the app.
  - **Portable exe**: the running file moves aside and the new one takes its place; on any error the old one goes back.
  - **Installed copy**: the new installer runs silently, in the same mode as the existing installation.
  - **Mac**: the new app is copied out of the disk image next to the old one, its signature checked, and swapped in once DuckNote has quit. A copy opened straight from the disk image, or in a folder it cannot write to, shows the release page instead.
  - **Impostazioni › Sistema › Aggiornamenti** turns the check off, shows what it found and checks on demand.

### Changed

- The builds no longer send Avalonia's build statistics.

| `DuckNote-0.0.18-macos-arm64.dmg` | macOS 14 or later (15+ recommended), Apple Silicon |
| `DuckNote-0.0.18-macos-x64.dmg` | macOS 14 or later (15+ recommended), Intel |

Not signed with a certificate: SmartScreen warns on the first run on Windows; on the Mac the app is ad-hoc signed, so the first time it is opened from **System Settings › Privacy & Security › Open Anyway**. `SHA256SUMS.txt` lists the hashes of every file — the same list the updater checks.
