### Fixed

- **On Windows the Mappa page did not load**: it stopped with an error about windows that cannot be shown ("Cannot set Visibility to Visible or call Show, ShowDialog…"). The web view that draws the map needs the WinRT graphics projection (`Microsoft.Windows.SDK.NET`), which the build did not include; the executable now carries it. Windows 10 1809 or later.
- **A web engine that cannot start no longer stops the window**: the Mappa page says what went wrong and the rest of DuckNote keeps working; the map saved in the note is untouched.
- **One error, one dialog**: an error raised while the error dialog was open no longer stacks a second dialog on the first.
